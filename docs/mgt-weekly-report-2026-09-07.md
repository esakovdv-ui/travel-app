## 3. Горячая линия 1144 — данных нет

Выгрузка `1144_20260907` пришла с фильтром: **4 карточки вместо примерно 80**. Даты создания — 04.09.2026, 20.08.2026, 18.07.2026 и 03.06.2026, то есть три из четырёх не за отчётную неделю. Три карточки относятся к одному договору (9502-104993).

Похоже, выгрузка сделана поиском по конкретному обращению, а не за период. Статистику по неделе, темам, форс-мажорам и менеджерам посчитать нельзя.

**Что осталось непроверенным:**

- Тема южных направлений держалась в топе обращений три недели подряд. За эту неделю данных нет.
- **Рекомендация из прошлого отчёта — единый протокол реагирования на форс-мажор с рейсами** (два случая вынужденной посадки за август: Владикавказ 18.08 и Челябинск 27.08, туристы сидели в аэропорту без еды и воды) — остаётся невыполненной. Проверить, были ли новые случаи, в этот раз не получилось.

С учётом того, что 52,7% сертификатов гасятся на юге (см. раздел 1), пробел в данных именно по этой теме неприятен. Нужна корректная выгрузка за 31.08–06.09.
