## Откуда взяты запросы

- Подсказки Яндекса, Москва, 19 ноября 2026. Это живые формулировки, не частотность и не число показов.
- Тексты [online.mosgortur.ru](https://online.mosgortur.ru/): туры, отели Подмосковья, лагеря, городские клубы, FAQ по сертификату.
- Правила сертификата на [mosgortur.ru/lok/navigator](https://mosgortur.ru/lok/navigator) и страница [как использовать сертификат](https://online.mosgortur.ru/for-tourists/how-get-certificate/): номинал 40 000 ₽ на лицо в сертификате, только Россия, активация через чат-бот в «Цифровой платформе МАКС», заявочная кампания на 2027 год — с 2 ноября по 10 декабря 2026.

Счётчик Метрики сайта в отчётах проекта — **90662828**. Токен лежит в секрете GitHub Actions `YANDEX_METRIKA_TOKEN` (синхронизация воронки 19 ноября 2026 отработала). Из этой среды секрет не читается, вызов отчёта без токена возвращает 403, запуск workflow запрещён. Выдачи Яндекса по бренду закрыта капчей. Поэтому в ядре нет визитов, позиций и показов.

## Как читать CSV

| Колонка | Смысл |
|---|---|
| приоритет | P0, P1 или P2 |
| задача | Какой из двух приоритетов закрывает запрос |
| кластер | Группа с одной посадочной и одним интентом |
| запрос | Формулировка как в подсказке или в правилах |
| интент | навигационный, информационный, коммерческий |
| посадочная | URL, который должен отвечать на запрос |
| позиция_подсказки | Место в подсказке Яндекса. Не показы в месяц |
| источник | Подсказка или правило продукта |
| комментарий | Где сейчас лежит ответ, если это не корзина online |

## Что мешает ядру попасть в поиск

19 ноября 2026 `https://online.mosgortur.ru/robots.txt` отдаёт:

```
User-agent: *
Disallow: /
```

Для всех роботов, включая Яндекс, сайт закрыт целиком. `sitemap.xml` отдаёт страницу 404. Пока это так, запросы из ядра не могут привести online в органическую выдачу, и в Метрике почти не будет поисковых фраз с Яндекса. Это наблюдение к данным, не список работ.
